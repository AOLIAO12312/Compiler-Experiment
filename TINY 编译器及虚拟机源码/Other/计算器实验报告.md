# 计算器实验报告 —— 两种实现路径

## 一、实验目的

独立完成两种计算器代码实现：
- **路径1**：基于BNF文法，去除左递归，处理继承属性与综合属性，新增非终结符与引线产生式
- **路径2**：基于EBNF文法，仅用综合属性，结合中缀转后缀实现

## 二、路径1：基于BNF文法的计算器

### 2.1 设计思路

#### 原始BNF文法（含左递归）

```
exp    → exp addop term | term
addop  → + | -
term   → term mulop factor | factor
mulop  → * | /
factor → ( exp ) | Number
```

此文法含有**左递归**（`exp → exp addop term`），无法直接用递归下降解析。

#### 去除左递归后的文法

引入新的非终结符 `exp'` 和 `term'`：

```
exp     → term exp'
exp'    → addop term exp' | ε
addop   → + | -
term    → factor term'
term'   → mulop factor term' | ε
mulop   → * | /
factor  → ( exp ) | Number
```

#### 属性设计

| 非终结符 | 继承属性(inh) | 综合属性(syn) |
|---------|-------------|-------------|
| exp'    | 左侧已累积的值 | 最终表达式的值 |
| term'   | 左侧已累积的值 | 最终项的值 |

**引线产生式**（Copy Rule）：当 `exp' → ε` 或 `term' → ε` 时，`syn = inh`，即继承属性直接"复制"为综合属性传递回去。

#### 属性传递过程示例

以 `3+4*5` 为例：

```
expr() 调用:
  term() → factor() 返回 3, term'(3) 返回 3
  exp_prime(3) 调用:
    match('+')
    term() → factor() 返回 4, term'(4):
      match('*'), factor() 返回 5, term'(4*5=20) → return 20
    exp_prime(3 + 20 = 23) → ε产生式, return 23
最终结果: 23
```

### 2.2 源代码

```c
/* 路径1：基于BNF文法的计算器
 * 去除左递归，处理继承属性与综合属性
 */

#include <stdio.h>
#include <stdlib.h>

char token;

int expr(void);
int exp_prime(int inh);
int term(void);
int term_prime(int inh);
int factor(void);

void error(void)
{
    fprintf(stderr, "error\n");
    exit(1);
}

void match(char expectedToken)
{
    if (token == expectedToken)
        token = getchar();
    else
        error();
}

/* exp → term exp'
 * exp.val = exp'(term.val).syn
 */
int expr(void)
{
    int temp = term();
    return exp_prime(temp);
}

/* exp' → addop term exp' | ε
 * 继承属性 inh 为左侧已累积的值
 * 综合属性 syn 为最终结果
 * 引线产生式：exp' → ε 时，syn = inh
 */
int exp_prime(int inh)
{
    if (token == '+') {
        match('+');
        int t = term();
        return exp_prime(inh + t);
    } else if (token == '-') {
        match('-');
        int t = term();
        return exp_prime(inh - t);
    }
    /* ε产生式：syn = inh */
    return inh;
}

/* term → factor term'
 * term.val = term'(factor.val).syn
 */
int term(void)
{
    int temp = factor();
    return term_prime(temp);
}

/* term' → mulop factor term' | ε
 * 继承属性 inh 为左侧已累积的值
 * 引线产生式：term' → ε 时，syn = inh
 */
int term_prime(int inh)
{
    if (token == '*') {
        match('*');
        int f = factor();
        return term_prime(inh * f);
    } else if (token == '/') {
        match('/');
        int f = factor();
        if (f == 0) {
            fprintf(stderr, "error: division by zero\n");
            exit(1);
        }
        return term_prime(inh / f);
    }
    /* ε产生式：syn = inh */
    return inh;
}

/* factor → ( exp ) | Number */
int factor(void)
{
    int temp = 0;

    if (token == '(') {
        match('(');
        temp = expr();
        match(')');
    } else if (token >= '0' && token <= '9') {
        ungetc(token, stdin);
        scanf("%d", &temp);
        token = getchar();
    } else {
        error();
    }

    return temp;
}

int main(void)
{
    int result;

    printf("BNF Calculator (left-recursion removed, inherited+synthesized attributes)\n");
    printf("Enter expression: ");

    token = getchar();
    result = expr();

    if (token == '\n')
        printf("Result = %d\n", result);
    else
        error();

    return 0;
}
```

### 2.3 关键技术点

1. **新增非终结符**：`exp'` 和 `term'` 是去除左递归后新增的非终结符
2. **继承属性传递**：通过函数参数 `inh` 将左侧累积值传入
3. **综合属性返回**：通过函数返回值实现综合属性向上传递
4. **引线产生式**：`ε` 产生式中 `return inh` 实现了继承属性到综合属性的"引线"
5. **左结合性保证**：通过尾递归 `exp_prime(inh + t)` 确保运算从左向右结合

## 三、路径2：基于EBNF文法的计算器

### 3.1 设计思路

#### EBNF文法

```
exp    → term { addop term }
addop  → + | -
term   → factor { mulop factor }
mulop  → * | /
factor → ( exp ) | Number
```

EBNF用 `{ }` 表示零次或多次重复，自然避免了左递归问题。

#### 实现方式：中缀转后缀 + 栈求值

采用两阶段方案：
1. **解析阶段**：递归下降解析中缀表达式，同时生成后缀（逆波兰）表达式序列
2. **求值阶段**：使用操作数栈对后缀表达式进行求值

所有属性均为**综合属性**（自底向上传递），不需要继承属性。

#### 后缀表达式生成规则

- 遇到数字：直接输出到后缀序列
- 遇到运算符：在两个操作数都输出后，再输出运算符

以 `3+4*5` 为例：
```
parse_exp():
  parse_term():
    parse_factor(): emit 3
    循环: token='+'不是'*'或'/', 退出
  循环: token='+', match('+')
  parse_term():
    parse_factor(): emit 4
    循环: token='*', match('*')
    parse_factor(): emit 5
    emit '*'
    循环结束
  emit '+'
  循环结束

后缀结果: 3 4 5 * +
求值: 4*5=20, 3+20=23
```

### 3.2 源代码

```c
/* 路径2：基于EBNF文法的计算器
 * 仅使用综合属性，结合中缀转后缀实现
 */

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

#define MAX_TOKENS 256
#define MAX_STACK  128

typedef enum { TK_NUM, TK_OP } TokenType;

typedef struct {
    TokenType type;
    int value;
} PostfixToken;

PostfixToken postfix[MAX_TOKENS];
int postfix_count = 0;

char token;

void error(void)
{
    fprintf(stderr, "error\n");
    exit(1);
}

void match(char expectedToken)
{
    if (token == expectedToken)
        token = getchar();
    else
        error();
}

void emit_number(int num)
{
    if (postfix_count >= MAX_TOKENS) error();
    postfix[postfix_count].type = TK_NUM;
    postfix[postfix_count].value = num;
    postfix_count++;
}

void emit_op(char op)
{
    if (postfix_count >= MAX_TOKENS) error();
    postfix[postfix_count].type = TK_OP;
    postfix[postfix_count].value = op;
    postfix_count++;
}

void parse_exp(void);
void parse_term(void);
void parse_factor(void);

/* exp → term { addop term } */
void parse_exp(void)
{
    parse_term();
    while (token == '+' || token == '-') {
        char op = token;
        match(token);
        parse_term();
        emit_op(op);
    }
}

/* term → factor { mulop factor } */
void parse_term(void)
{
    parse_factor();
    while (token == '*' || token == '/') {
        char op = token;
        match(token);
        parse_factor();
        emit_op(op);
    }
}

/* factor → ( exp ) | Number */
void parse_factor(void)
{
    if (token == '(') {
        match('(');
        parse_exp();
        match(')');
    } else if (token >= '0' && token <= '9') {
        int num;
        ungetc(token, stdin);
        scanf("%d", &num);
        token = getchar();
        emit_number(num);
    } else {
        error();
    }
}

/* 后缀表达式求值 */
int evaluate_postfix(void)
{
    int stack[MAX_STACK];
    int top = -1;

    for (int i = 0; i < postfix_count; i++) {
        if (postfix[i].type == TK_NUM) {
            stack[++top] = postfix[i].value;
        } else {
            if (top < 1) error();
            int right = stack[top--];
            int left  = stack[top--];
            switch (postfix[i].value) {
                case '+': stack[++top] = left + right; break;
                case '-': stack[++top] = left - right; break;
                case '*': stack[++top] = left * right; break;
                case '/':
                    if (right == 0) {
                        fprintf(stderr, "error: division by zero\n");
                        exit(1);
                    }
                    stack[++top] = left / right;
                    break;
            }
        }
    }

    if (top != 0) error();
    return stack[0];
}

void print_postfix(void)
{
    printf("Postfix: ");
    for (int i = 0; i < postfix_count; i++) {
        if (postfix[i].type == TK_NUM)
            printf("%d ", postfix[i].value);
        else
            printf("%c ", postfix[i].value);
    }
    printf("\n");
}

int main(void)
{
    int result;

    printf("EBNF Calculator (synthesized attributes + infix-to-postfix)\n");
    printf("Enter expression: ");

    token = getchar();
    parse_exp();

    if (token != '\n')
        error();

    print_postfix();
    result = evaluate_postfix();
    printf("Result = %d\n", result);

    return 0;
}
```

### 3.3 关键技术点

1. **EBNF循环替代递归**：`while` 循环实现 `{ }` 重复，天然保证左结合性
2. **仅用综合属性**：数字作为综合属性直接输出，运算符在操作数之后输出
3. **中缀转后缀**：解析过程中同步生成后缀表达式，运算符优先级由文法层次决定
4. **栈求值**：后缀表达式用操作数栈线性求值，时间复杂度O(n)

## 四、两种路径对比

| 对比维度 | 路径1 (BNF) | 路径2 (EBNF) |
|---------|------------|-------------|
| 文法形式 | BNF，需去除左递归 | EBNF，天然无左递归 |
| 属性类型 | 继承属性 + 综合属性 | 仅综合属性 |
| 新增非终结符 | exp', term' | 无 |
| 引线产生式 | 有（ε产生式中syn=inh） | 无 |
| 左结合实现 | 尾递归传参 | while循环 |
| 求值方式 | 边解析边计算 | 先转后缀再求值 |
| 代码复杂度 | 中等 | 稍高（两阶段） |
| 中间表示 | 无 | 后缀表达式 |

## 五、实验结果

### 编译命令

```bash
gcc -o Calculator_BNF Calculator_BNF.c -Wall
gcc -o Calculator_EBNF Calculator_EBNF.c -Wall
```

### 测试结果

| 输入表达式 | 路径1输出 | 路径2后缀 | 路径2输出 |
|-----------|----------|----------|----------|
| `3+4*5`   | Result = 23 | `3 4 5 * +` | Result = 23 |
| `10-2*3`  | Result = 4  | `10 2 3 * -` | Result = 4 |
| `(1+2)*3` | Result = 9  | `1 2 + 3 *` | Result = 9 |
| `100/5+3` | Result = 23 | `100 5 / 3 +` | Result = 23 |
| `2-3-4`   | Result = -5 | `2 3 - 4 -` | Result = -5 |
| `12/3/2`  | Result = 2  | `12 3 / 2 /` | Result = 2 |

两种实现均正确处理了：
- **运算符优先级**：`*`、`/` 高于 `+`、`-`
- **左结合性**：`2-3-4 = (2-3)-4 = -5`，`12/3/2 = (12/3)/2 = 2`
- **括号改变优先级**：`(1+2)*3 = 9`

## 六、与原始Calculator.c的对比

原始 `Calculator.c` 使用简单递归实现，存在以下问题：
- `exp()` 中递归调用 `temp+=exp()` 导致右结合（如 `2-3-4` 可能得到错误结果）
- 没有明确的属性传递机制

本实验的两种实现均修正了这些问题，并体现了编译原理中属性文法的核心概念。
