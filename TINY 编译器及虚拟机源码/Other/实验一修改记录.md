# 实验一 Calculator.c 代码修改记录

## 修改要求

1. 添加 `/` 运算符，实现除运算功能
2. 添加单目运算符 `+` 和 `-`，实现相关计算功能
3. 双目运算符 `+`、`-`、`*`、`/` 按右结合方式进行计算

---

## 修改前的文法（EBNF）

```
<exp>    → <term> { <addop> <term> }
<addop>  → + | -
<term>   → <factor> { <mulop> <factor> }
<mulop>  → *
<factor> → ( <exp> ) | Number
```

## 修改后的文法（EBNF）

```
<exp>    → <term> <addop> <exp> | <term>
<addop>  → + | -
<term>   → <factor> <mulop> <term> | <factor>
<mulop>  → * | /
<factor> → ( <exp> ) | <unaryop> <factor> | Number
<unaryop>→ + | -
```

---

## 具体修改内容

### 1. 添加 `/` 运算符（term 函数）

**修改前：**

```c
int term(void)
{
    int temp=factor();
    while (token=='*')
    {
        match('*');
        temp*=factor();
    }
    return temp;
}
```

**修改后：**

```c
int term(void)
{
    int temp=factor();
    if ( (token=='*') || (token=='/') )
    {
        switch (token)
        {
        case '*':  match('*');
                   temp*=term();
                   break;
        case '/':  match('/');
                   temp/=term();
                   break;
        }
    }
    return temp;
}
```

**改动说明：** 在 `term` 函数中增加对 `/` 的识别和处理，使用整数除法 `/=` 计算结果。

---

### 2. 添加单目运算符 `+` 和 `-`（factor 函数）

**修改前：**

```c
int factor(void)
{
    int temp;

    if (token=='(')
    {
        match ('(');   temp = exp();   match(')');
    }
    else
        if (token>=48 && token<=57)  // if (isdigit(token))
        {
            ungetc(token,stdin);
            scanf("%d",&temp);
            token = getchar();
        }
        else error();

    return temp;
}
```

**修改后：**

```c
int factor(void)
{
    int temp;

    if (token=='(')
    {
        match('(');   temp = exp();   match(')');
    }
    else if (token=='+')
    {
        match('+');
        temp = factor();
    }
    else if (token=='-')
    {
        match('-');
        temp = -factor();
    }
    else if (token>=48 && token<=57)  // if (isdigit(token))
    {
        ungetc(token,stdin);
        scanf("%d",&temp);
        token = getchar();
    }
    else error();

    return temp;
}
```

**改动说明：**
- 单目 `+`：匹配后递归调用 `factor()`，值不变
- 单目 `-`：匹配后递归调用 `factor()`，结果取反
- 支持连续单目运算符，如 `--5` 结果为 `5`

### 3. 双目运算符改为右结合（exp 和 term 函数）

**核心改动：将 `while` 循环改为 `if` + 递归调用**

#### exp 函数

**修改前（左结合）：**

```c
int exp(void)
{
    int temp=term();
    while ( (token=='+') || (token=='-') )  // 循环：从左往右累积
        switch (token)
        {
        case '+':  match('+');
                   temp+=term();
                   break;
        case '-':  match('-');
                   temp-=term();
                   break;
        }
    return temp;
}
```

**修改后（右结合）：**

```c
int exp(void)
{
    int temp=term();
    if ( (token=='+') || (token=='-') )  // 递归：先算右边
        switch (token)
        {
        case '+':  match('+');
                   temp+=exp();  // 递归调用 exp()
                   break;
        case '-':  match('-');
                   temp-=exp();  // 递归调用 exp()
                   break;
        }
    return temp;
}
```

#### term 函数

同理，`term()` 中 `temp*=factor()` 改为 `temp*=term()`，`temp/=factor()` 改为 `temp/=term()`。

**改动说明：**
- 左结合用 `while` 循环：每次将新结果累加到左边变量，天然从左往右计算
- 右结合用 `if` + 递归：递归让右侧表达式先完成计算，再与左边结合

## 测试验证

| 表达式 | 右结合计算过程 | 结果 |
|--------|---------------|------|
| `6/2` | `6/2` | 3 |
| `10/3` | `10/3`（整数除法） | 3 |
| `-5+3` | `(-5)+3` | -2 |
| `+3*4` | `(+3)*4` | 12 |
| `--5` | `-(-5)` | 5 |
| `8-3-2` | `8-(3-2)` | 7（左结合则为 3） |
| `8/4/2` | `8/(4/2)` | 4（左结合则为 1） |
